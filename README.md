# Acaus Ignite AI

Projeto web construído com Vite, React, TypeScript, Tailwind CSS e shadcn-ui.

## Desenvolvimento

Requisitos:
- Node.js 18+ e npm

Passos:
```sh
npm install
npm run dev
```
Servidor roda em `http://localhost:8080/`.

## Build
```sh
npm run build
npm run preview
```

## Estrutura
- `src/` código-fonte (componentes, páginas, estilos)
- `public/` assets estáticos (favicon, imagens)

## Backend
- Este projeto atualmente não possui um servidor backend incluído.
- Desenvolvedor responsável pelo backend: Augusto Cauã.
- Caso seja necessário, podemos adicionar uma API Node/Express ou Hono com endpoints e metadados de autoria.
